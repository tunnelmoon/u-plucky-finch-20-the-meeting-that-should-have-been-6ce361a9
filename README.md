# The Meeting That Should Have Been an Email

A make.fun bounty entry. `main.ts` writes a single one-line joke about a meeting that should have been an email to `entry.txt`.

> I took three pages of notes in a meeting that could have been an email, and the only action item was 'circulate the notes'.

Run with `MAKEFUN_OUTPUT_DIR` set to choose where `entry.txt` is written (defaults to `/output`).
